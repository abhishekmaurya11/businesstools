How to use the generator

  1. Enter your product name — this appears in every section.
  2. Optionally add a category (used in the title).
  3. List your main features, separated by commas.
  4. Describe your target audience in a few words.
  5. Pick a tone of voice. Try a few — each produces different copy patterns.
  6. Click Generate description. Copy each section into your listing and edit it to fit your brand voice.

What this tool does — and doesn't do

Template-based, not AI. This generator does not call any AI service. It fills reusable copywriting patterns with your inputs. The result is a first draft, not a finished listing — always review and edit before publishing.

How the templates work

Each tone has its own set of sentence patterns for the title, description, feature bullets, and call to action. Feature bullets are paired with short benefit phrases using keyword matching (e.g. "battery" → "for all-day use"). When no keyword matches, the feature itself becomes the bullet.

Frequently asked questions

Is this really not AI?

Correct. No external API is called. The output is generated entirely in your browser using predefined templates. It never sends your product data anywhere.

Can I edit the output?

Yes — and you should. Treat the output as a first draft. Every section has a copy button so you can paste it into your listing and refine it.

Does it write in my brand voice?

It gets close if you pick the right tone, but it can't learn your specific voice. Edit word choices, add specifics, and remove anything that doesn't fit.

Will it work for any product category?

Yes. The category is used mainly in the title. Feature and audience language is category-agnostic, so it works for electronics, apparel, home goods, and more.

How many features should I enter?

Three to six is ideal. Too few and the bullets look thin; too many and the description gets crowded. Keep each feature short (2–6 words).
